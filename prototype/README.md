# andrecoach.com: redesign prototype

A single-page redesign proposal in a light lavender style, based on the SEO & GEO audit (Oct 15, 2026).

- `index.html`: page source, as published to the Claude artifact
- `standalone.html`: the same page with a full HTML document wrapper, so you can open it straight in a browser

The **Show audit notes** button (bottom right) highlights which audit fix each section covers. Text with a dotted underline is a placeholder the client needs to fill in: full name, photo, prices, case-study figures, phone number and testimonials.
